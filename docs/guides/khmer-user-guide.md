# សៀវភៅណែនាំការប្រើប្រាស់ Vishnu Creator (Khmer User Guide)

សូមស្វាគមន៍មកកាន់ **Vishnu Creator** ដែលជាកម្មវិធីកាត់ត និងបញ្ចូលសំឡេងវីដេអូឆ្លាតវៃដោយប្រើបញ្ញាសិប្បនិម្មិត (AI) ដោយផ្តោតជាចម្បងលើ **ភាសាខ្មែរ (Khmer-First)**។ កម្មវិធីនេះដំណើរការនៅលើម៉ាស៊ីនផ្ទាល់ខ្លួនរបស់អ្នក (Local-first) ធានាសុវត្ថិភាពទិន្នន័យខ្ពស់ និងមិនចាំបាច់ពឹងផ្អែកលើអ៊ីនធឺណិតខ្លាំងនោះឡើយ។

---

## ១. ការចាប់ផ្តើមដំបូង (Getting Started)

### ការបើកដំណើរការកម្មវិធី
- ប្រសិនបើអ្នកប្រើប្រាស់ **កម្មវិធីលើកុំព្យូទ័រ (Desktop App)**៖ សូមចុចពីរដងលើរូបតំណាង Vishnu Creator នៅលើ Desktop ដើម្បីបើកកម្មវិធី។
- ប្រសិនបើអ្នកដំណើរការតាម **Web Browser**៖ សូមចូលទៅកាន់អាសយដ្ឋាន `http://127.0.0.1:19861` នៅក្នុងកម្មវិធី Google Chrome ឬ Microsoft Edge។
- នៅពេលបើកដំបូង ប្រព័ន្ធនឹងពិនិត្យមើលម៉ាស៊ីន និងបង្ហាញសារ «Local Runtime ដំណើរការប្រក្រតី» នៅផ្នែកខាងលើនៃទំព័រ។

---

## ២. ការបង្កើតគម្រោង និងបញ្ចូលវីដេអូ (Project & Video Import)

1. **បង្កើតគម្រោងថ្មី (New Project)**៖
   - ចុចលើប៊ូតុង **«បង្កើតគម្រោងថ្មី»** ឬជ្រើសរើសគម្រោងដែលមានស្រាប់ពីរបារចំហៀងខាងឆ្វេង។
2. **បញ្ចូលវីដេអូ (Import Media)**៖
   - អ្នកអាចអូសទម្លាក់ (Drag and Drop) ឯកសារវីដេអូប្រភេទ `.mp4`, `.mov`, `.mkv` ឬ `.webm` ចូលទៅក្នុងផ្ទាំងការងារ ឬចុចលើប៊ូតុងជ្រើសរើសឯកសារពីកុំព្យូទ័ររបស់អ្នក។
3. **ជ្រើសរើសទម្រង់ការងារ (Template)**៖
   - ជ្រើសរើសយក **«Smart Dubbing»** (ការបញ្ចូលសំឡេងឆ្លាតវៃ) ឬ **«Video Translation»** (ការបកប្រែវីដេអូ) ដើម្បីចូលទៅកាន់ស្ទូឌីយោ Dub Studio។

## ៣. ស្ទូឌីយោបញ្ចូលសំឡេង Dub Studio (Dub Studio Workflow)

ដំណើរការបញ្ចូលសំឡេងត្រូវបានរៀបចំជាជំហានស្វ័យប្រវត្តិចំនួន ៦ យ៉ាងរលូន៖

```
[១. ទាញសំឡេង] ➔ [២. បំលែងជាអក្សរ] ➔ [៣. បកប្រែជាខ្មែរ] ➔ [៤. បំបែកភ្លេង] ➔ [៥. បញ្ចូលសំឡេងថ្មី] ➔ [៦. ចេញវីដេអូសម្រេច]
```

### ជំហានទី ១៖ ការទាញយកអក្សរពីសំឡេងដើម (Transcription / ASR)
- ប្រព័ន្ធនឹងស្ដាប់សំឡេងដើមក្នុងវីដេអូ ហើយបង្កើតជាអក្សររត់ (Subtitles) ដោយស្វ័យប្រវត្តិ។
- កម្មវិធីគាំទ្រម៉ាស៊ីន Faster-Whisper នៅលើកុំព្យូទ័រផ្ទាល់ ក៏ដូចជាសេវា Cloud (ដូចជា Gemini, Groq, Whisper API) ទៅតាមជម្រើសរបស់អ្នក។

### ជំហានទី ២៖ ការបកប្រែទៅជាភាសាខ្មែរប្រចាំថ្ងៃ (Translation)
- អត្ថបទដើមនឹងត្រូវបកប្រែមកជា **ភាសាខ្មែរនិយាយប្រចាំថ្ងៃ** ដែលមានលក្ខណៈធម្មជាតិ មិនរឹង ឬឆ្គងដូចការបកប្រែតាមម៉ាស៊ីនទូទៅឡើយ។
- ប្រព័ន្ធរក្សាល្បឿនអានសមស្របទៅតាមប្រវែងវិនាទីនៃវីដេអូនីមួយៗ (Fitted CPS)។

---

## ៤. វិធានអក្ខរាវិរុទ្ធ និងការកែសម្រួលអក្សរខ្មែរ (Khmer Orthography Rules)

នៅពេលអ្នកត្រួតពិនិត្យ ឬកែសម្រួលអក្សររត់នៅក្នុងផ្ទាំង Subtitle Editor សូមអនុវត្តតាមគោលការណ៍ខាងក្រោម ដើម្បីឱ្យសំឡេងអាន និងការបង្ហាញអក្សរមានភាពត្រឹមត្រូវល្អឥតខ្ចោះ៖

1. **គ្មានការដកឃ្លារវាងពាក្យ (No Spaces Between Words)**៖
   - ភាសាខ្មែរសរសេរជាប់គ្នាជាឃ្លា។ សូមកុំចុច Spacebar នៅចន្លោះពាក្យ ពីព្រោះវាធ្វើឱ្យខូចចង្វាក់អានរបស់ម៉ាស៊ីន TTS។
2. **ដកឃ្លាតែពេលចប់ឃ្លាប៉ុណ្ណោះ (Spaces Only at Clauses)**៖
   - ការដកឃ្លាត្រូវធ្វើឡើងនៅចន្លោះឃ្លានិយាយ ឬបន្ទាប់ពីសញ្ញាខណ្ឌ (`។`) ប៉ុណ្ណោះ។
3. **រក្សាជើងព្យញ្ជនៈឱ្យត្រឹមត្រូវ (Preserve Subscript Consonants)**៖
   - ជើងព្យញ្ជនៈទាំងអស់ (ប្រើសញ្ញា ្ / Coeng U+17D2) ដូចជា «ខ្ញុំ», «កម្ពុជា», «ស្ដាប់» ត្រូវវាយឱ្យជាប់ជាមួយតួអក្សរដើមជានិច្ច។
4. **ប្រើសញ្ញាខណ្ឌខ្មែរ (Use Khmer Punctuation `។`)**៖
   - សូមប្រើសញ្ញា «។» នៅចុងល្បះ ជៀសវាងការប្រើសញ្ញាចុចបែបបស្ចិមប្រទេស (`.`) នៅក្នុងអត្ថបទខ្មែរ។
5. **ប្រើលេខអារ៉ាប់ (Use Arabic Numerals 0–9)**៖
   - សម្រាប់ការកត់ត្រាចំនួន លេខកាលបរិច្ឆេទ ឬទិន្នន័យលេខ សូមប្រើលេខអារ៉ាប់ (ដូចជា 1, 2, 2026) ដើម្បីឱ្យប្រព័ន្ធអានសំឡេងបានត្រឹមត្រូវនិងរលូន។

## ៥. ការជ្រើសរើសសំឡេងអានភាសាខ្មែរ (TTS Voice Selection)

Vishnu Creator ផ្តល់ជូននូវជម្រើសសំឡេងខ្មែរដ៏សម្បូរបែប៖

### ១. សំឡេងស្តង់ដារ Edge-TTS (ដំណើរការលឿន មិនត្រូវការ GPU ធំ)
- **ស្រីមុំ (`km-KH-SreymomNeural`)**៖ សំឡេងនារី ផ្អែមរលូន ច្បាស់ល្អ ស័ក្តិសមបំផុតសម្រាប់ការអានព័ត៌មាន ភាពយន្តឯកសារ ឬការរៀបរាប់ដំណើររឿង។
- **ពិសិដ្ឋ (`km-KH-PisethNeural`)**៖ សំឡេងបុរស រឹងមាំ ថ្លៃថ្នូរ ស័ក្តិសមសម្រាប់ការបង្រៀន ការធ្វើបទបង្ហាញ ឬវីដេអូអាជីវកម្ម។

### ២. សំឡេងក្លូន VoxCPM2 (Zero-Shot Voice Cloning)
- ប្រសិនបើអ្នកចង់ប្រើសំឡេងផ្ទាល់ខ្លួន ឬសំឡេងតួអង្គណាមួយ អ្នកគ្រាន់តែបញ្ចូលឯកសារសំឡេងគំរូរយៈពេល **៣ ទៅ ១០ វិនាទី**។
- ប្រព័ន្ធនឹងចម្លងទឹកដម និងចង្វាក់សំឡេងនោះមកអានភាសាខ្មែរភ្លាមៗ។
- រាល់សំឡេងដែលបង្កើតឡើងដោយ VoxCPM2 សុទ្ធតែមានបង្កប់សញ្ញាសម្គាល់សុវត្ថិភាព (Watermark) ស្របតាមក្រមសីលធម៌ AI។

## ៦. ការបំបែកភ្លេង និងលាយសំឡេង (Vocal Separation & Audio Mixing)

- **បំបែកភ្លេងដោយ Demucs**៖ កម្មវិធីនឹងបំបែកសំឡេងមនុស្សនិយាយចេញពីភ្លេងផ្ទៃខាងក្រោយ និងសំឡេង Effects ដោយស្វ័យប្រវត្តិ។
- **បច្ចេកវិទ្យា Audio Ducking**៖ នៅពេលមានសំឡេងខ្មែរនិយាយ សំឡេងភ្លេងផ្ទៃខាងក្រោយនឹងត្រូវបន្ថយដោយស្វ័យប្រវត្តិចុះមកត្រឹម ៣០% ហើយនឹងកើនឡើងវិញនៅពេលចប់ការនិយាយ ធ្វើឱ្យវីដេអូមានលក្ខណៈដូចការបញ្ចូលសំឡេងអាជីព។
- **តម្រឹមល្បឿន (Time Synchronization)**៖ ប្រព័ន្ធនឹងសម្រួលល្បឿនសំឡេងអានឱ្យត្រូវគ្នានឹងចលនានិយាយក្នុងវីដេអូដើម ដោយមិនធ្វើឱ្យសំឡេងប្រែប្រួលសំនៀងឡើយ។

## ៧. ការនាំចេញវីដេអូជាសម្រេច (Export & Subtitle Burn-In)

1. **ការកំណត់អក្សររត់លើវីដេអូ**៖
   - អ្នកអាចជ្រើសរើស «បង្កប់អក្សររត់លើវីដេអូ (Burn-in Subtitles)» ដោយប្រើពុម្ពអក្សរ **Noto Sans Khmer** ដែលច្បាស់ មិនបាក់ជើង និងស្រួលមើល។
   - អ្នកអាចជ្រើសរើសបង្ហាញតែអក្សរខ្មែរ ឬបង្ហាញទាំងភាសាដើមនិងភាសាខ្មែរទន្ទឹមគ្នា។
2. **ទាញយកវីដេអូ (Download MP4)**៖
   - នៅពេលដំណើរការចប់សព្វគ្រប់ អ្នកអាចចុច **«Download Dubbed Video»** ដើម្បីរក្សាទុកវីដេអូកម្រិតច្បាស់ (Full HD / 4K) លើកុំព្យូទ័ររបស់អ្នក។
   - អ្នកក៏អាចទាញយកតែឯកសារសំឡេង (`.m4a` / `.wav`) ឬឯកសារអក្សររត់ (`.srt` / `.ass`) ដោយឡែកបានផងដែរ។

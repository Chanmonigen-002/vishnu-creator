| T4.5 | Time-sync: stretch/compress TTS per segment within limits; flag segments that cannot fit | done | 2026-10-28 (branch `phase-4/time-sync`). **Before:** `jobs.py` concatenated TTS segments back to back with ffmpeg `concat`, ignoring subtitle times, so the dub drifted from the video. **Now:** `services/dub-engine/vishnu_dub/timesync.py` places each segment at its subtitle start; a segment longer than its slot first uses the gap before the next subtitle, then is sped up with `atempo` up to `timesync_max_speedup` (default 1.3, env `TIMESYNC_MAX_SPEEDUP`); if it still does not fit, the next segment is delayed just enough to avoid overlap and the segment is flagged `overflow`. Live run with real Khmer Edge-TTS (`km-KH-SreymomNeural`): seg 0 window 0.5–3.5 s, speech 2.50 s → placed 0.5–3.00 s `fit`; seg 1 window 4.0–5.5 s, speech 4.51 s → 1.3x, placed 4.0–7.47 s `overflow`; seg 2 window 6.0–8.0 s, speech 1.92 s → delayed, 1.3x, placed 7.47–8.95 s `sped_up`; output WAV 9.05 s, 24 kHz mono (ffprobe).

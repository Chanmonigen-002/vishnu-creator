## Folder layout

The repo-wide layout (backend, frontend, services, data, reference) is in [project/STRUCTURE.md](project/STRUCTURE.md).

| Folder | Contents | Owner |
|---|---|---|
| `project/` | Master plan and [repo structure](project/STRUCTURE.md) | Vishnu Creator |
| `tasks/` | Phase task files (`phase-<n>-<name>.md`): the to-do list with status and evidence | Vishnu Creator |
| `adr/` | Architecture Decision Records (`NNNN-title.md`) | Vishnu Creator |
| `guides/` | User-facing guides: Dub Studio, user guide, transcription, credentials | Vishnu Creator + upstream |
| `engineering/` | Engineering notes and design docs: runtime API, video translation, subtitles, diagnostics (`engineering/assets/` holds their data) | upstream + Vishnu |
| `providers/` | AI provider research | Vishnu Creator |
| `plans/` | Active implementation plans. `plans/archive/` holds superseded Vishnu plans | Vishnu Creator |
| `handoffs/` | Dated handoff notes between agents and sessions | Vishnu Creator |
| `templates/` | Templates (handoff note) | Vishnu Creator |
| `operations/` | Release runbooks and operating notes | upstream |
| `performance/` | Performance baselines | upstream |
| `test-reports/` | Saved test reports and screenshots (evidence for tasks) | Vishnu Creator |
| `contributing/` | Skill and template contribution guides | upstream |
| `i18n/<lang>/` | Translated READMEs and contributing guides | upstream |
| `images/`, `videos/` | Media used by docs (`star-coverage.json` is generated by CI) | — |
| `archive/upstream/` | Historical upstream plans, notes and reports (Chinese content, English file names) | upstream, read-only |

## Conventions

- New docs are written in English. Use lowercase kebab-case file names, plus a date prefix (`YYYY-MM-DD-`) for time-bound plans and reports.
- Put each doc in the folder that matches its type; don't add new loose files at the top of `docs/`.
- Plans describe intent; task files record progress; ADRs record decisions. Don't mix them.

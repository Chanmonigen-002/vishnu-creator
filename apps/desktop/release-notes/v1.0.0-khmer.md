# Vishnu Creator v1.0.0-khmer

Vishnu Creator v1.0.0-khmer marks the first official release of the Khmer-first agentic video creation and dubbing desktop platform.

## What's New

- Added complete end-to-end Khmer video dubbing pipeline with natural spoken Khmer (km) as the primary target language.
- Integrated high-speed, zero-GPU Microsoft Edge-TTS with Sreymom (km-KH-SreymomNeural) and Piseth (km-KH-PisethNeural) voices for fast narration.
- Integrated VoxCPM2 zero-shot multilingual voice cloning with customizable reference samples (3-10 seconds) and Nyquist-safe ultrasonic watermarking.
- Added Demucs HTDemucs acoustic vocal separation with automated audio ducking to preserve background music and sound effects.
- Implemented Khmer typography and subtitle burn-in using Noto Sans Khmer with strict script integrity rules: zero inter-word spaces, intact consonant clusters (coeng), and standard punctuation.
- Unified the Creator collaboration experience under a shared CreatorCollaborationPanel across all creative studios (Smart Dubbing, Video Translation, Video Generation, Cover Generation).
- Built in-repo Python Dub Engine service running over secure loopback HTTP (127.0.0.1:8765) with automatic process supervision from the local Daemon.
- Added adaptive hardware tiers (T1/T2/T3) automatically optimizing inference between CPU INT8 Faster-Whisper and CUDA GPU FP16 acceleration.
- Built atomic model download manager with pre-flight disk reservation and streaming SHA-256 verification storing models on the drive with highest available free space.
- Expanded transcription provider integrations with Faster-Whisper, FunASR, Gemini, OpenAI Whisper, Deepgram, and Groq.
- Added comprehensive documentation including Dub Studio guide, Local Dub Engine guide, and user-facing Khmer user guide.
- Added formal open-source attribution notice for OpenCreator, ZastTranslate, VoxCPM, Faster-Whisper, Demucs, and Noto Sans Khmer.
